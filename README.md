# ShellForge

ShellForge is a custom shell project developed in C on Ubuntu.

## Milestones

1. User input and shell prompt
2. Command tokenization
3. Command organization using structure
4. Command execution using fork(), execvp() and waitpid()
5. Built-in cd command

## Technologies Used

- C
- Linux/Ubuntu
- GCC
- Git
- GitHub

## Files

- shellforge1.c - User input and shell prompt
- shellforge2.c - Command tokenizer
- shellforge3.c - Command organizer using structure
- shellforge4.c - Command execution
- shellforge5.c - Built-in cd command
